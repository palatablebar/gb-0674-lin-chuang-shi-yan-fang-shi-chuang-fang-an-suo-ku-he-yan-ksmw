# 访视与冻结定义

样例均为虚构编号，无身份信息。受试者入组日期由subjects表唯一确定，记录中的入组基准必须完全一致。采样日期和入组日期均转为Asia/Shanghai日历日期，差值为访视日；时刻先统一UTC。
方案选择按当前受试者assignment和该次发生时刻查半开生效窗，匹配必须唯一，不能使用全局最新方案。v1访视V1=[5,10)、V2=[12,17)；v2为[6,11)、[13,18)。受试者00001于10月10日转v2，其他受试者仍用v1。
PRIMARY计入访视完成，RETEST只替代该次测量值。首次记录必须唯一且在访视窗内。缺首次访视、重复首次和窗外访视均阻断，复检不能填补漏访或消除原偏离。
复检须引用同受试者同访视的PRIMARY，晚于原采样且不超过72小时，版本必须更高。同最高版本复检冲突时保留原结果并阻断。所有检验值以mg/dL输出，g/L乘100。

## 数据截止口径

本批数据截止日为context的cutoff（Asia/Shanghai日历日，含当日，样例为2026-11-17）。方案版本、成熟状态、偏离判断、复检结论、锁库检查与冻结凭证共用同一截止日；cutoff进入批次digest、manifest与冻结seal，改截止即生成新批次，原批次保留。
受试者某规定访视的预期窗口按截止时刻有效方案计算，窗止日=入组日历日+窗终日。窗止日≤截止日为已到期：缺首次访视记MISSING_PRIMARY并阻断；窗外记录记WINDOW_EARLY/LATE并阻断。窗止日>截止日为未到期：记PENDING_MATURITY待成熟，不判漏访、不阻断，随批次与冻结凭证列示，下一批重核。
锁库须所有已到期规定访视完成，无偏离、复检问题和隔离行；待成熟项不拖住锁库。冻结包包含每条选定结果、原始行号、方案版本与访视窗，并列明本批截止日、待成熟项与阻断原因。此工具只验证试验数据完整性，不做诊断判断或生产锁库。
